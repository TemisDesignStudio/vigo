# برنامه اجرای MVP Vigo

## قواعد اجرای مراحل

- هر بخش مستقل پیاده‌سازی، با آزمون خودکار و اجرای واقعی Docker بررسی، و برای تأیید کاربر گزارش می‌شود.
- تا تأیید صریح کاربر، تغییری از آن بخش Git commit نمی‌شود و کار بخش بعد آغاز نمی‌گردد.
- دامنه MVP به ایجاد، مشاهده، ویرایش و تغییر وضعیت محدود است؛ حذف داده در هیچ‌یک از بخش‌ها پیاده‌سازی نمی‌شود.
- طراحی و رفتار فعلی سایت عمومی Vigo باید حفظ شود مگر تغییری که صریحاً در این برنامه آمده باشد.
- تمام متن‌های خطای قابل‌نمایش به کاربر فارسی هستند.
- کلید OpenRouter فقط از `OPENROUTER_API_KEY` در `.env` خوانده می‌شود و مدل فقط `openrouter/free` است.

## وضعیت اولیه تأییدشده

- کدهای Next.js در `frontend/` قرار دارند و خروجی استاتیک آن‌ها در `frontend/out/` ساخته می‌شود.
- صفحه عمومی در `frontend/app/page.jsx` و رابط چت‌بات در `frontend/app/Chatbot.jsx` قرار دارد. انتقال اتصال OpenRouter به FastAPI در بخش هشتم انجام می‌شود.
- Docker، FastAPI، اسکریپت‌های اجرا و آزمون‌های خروجی استاتیک آماده‌اند؛ SQLite هنوز پیاده‌سازی نشده است.
